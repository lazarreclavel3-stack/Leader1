# Robo_CFO

Bespoke AI finance agent: bookkeeper, tax/EA, and CFO for a solo-owner therapy practice.

See [BUILD_PLAN.md](BUILD_PLAN.md) for the 6-phase development roadmap.

## Quick Start

### Setup

1. Create a Python virtual environment:
   ```bash
   python3.11 -m venv venv
   source venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   pip install -e ".[dev]"
   ```

3. Configure environment:
   ```bash
   cp .env.example .env
   # Edit .env with your database URL and API keys
   ```

4. Run database migrations:
   ```bash
   alembic upgrade head
   ```

5. Start the server:
   ```bash
   python -m uvicorn src.robo_cfo.api.main:app --reload
   ```

The API will be available at http://localhost:8000. Health check: http://localhost:8000/health

## Database Models

### Core Tables
- **clients**: Client account with financial info and platform connections
- **users**: User accounts with roles (owner, backup_approver, reviewer)
- **bank_accounts**: Connected bank accounts from Plaid
- **transactions**: Bank transactions with AI categorization
- **cash_forecasts**: 13-week cash flow forecasts
- **rules**: Financial rules (thresholds, checks)
- **alerts**: Alerts generated by rule evaluation
- **approvals**: Payment approval requests with audit trail
- **audit_log**: Append-only log of all reads, writes, alerts, approvals

### Notes
- Every read and write is logged to `audit_log`
- All timestamps are UTC (`datetime.utcnow()`)
- Foreign keys ensure referential integrity
- Indexes on frequently queried columns (client_id, created_at, status, etc.)
