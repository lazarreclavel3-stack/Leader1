# Leader1

A tiny legal tax-planning example.

## Run

```bash
python3 tax_planner.py
```

## What it does

- Takes a tax profile (income, deductions, pre-tax contributions, credits).
- Estimates taxable income and tax liability with simplified brackets.
- Suggests legal strategies to reduce taxes (e.g., retirement accounts, HSA, deductions).

> This project is for educational planning only, not tax advice.
